Dev PC:
================================================================
###: Clear old service
sc query MProjectAgent
sc qc MProjectAgent      # xem BINARY_PATH_NAME hiện tại

sc stop MProjectAgent 
sc delete MProjectAgent

Đảm bảo không còn tiến trình giữ file:
Get-Process MProjectAgent, MProjectLauncher -ErrorAction SilentlyContinue | Stop-Process -Force

----------------------------------------------------------------
###: Build new program
cd <repo_root>          # vd: C:\Users\Administrator\Desktop\TESS\MProject
powershell -File scripts\package-agent.ps1 -Configuration Release

copy vào C:\Program Files\MProjectAgent


================================================================

Agent PC:
================================================================
###: Cài + chạy service (chạy từ thư mục mới, quyền Admin)

& "C:\Program Files\MProjectAgent\MProjectAgent.exe" install

###: Sửa file trong thư mục cài C:\Program Files\MProjectAgent\appsettings.json (KHÔNG phải file trong repo):


"Agent": {
  "ServerUrl": "http://<server-host>:<port>",   // vd http://localhost:5107 hoặc https://192.168.x.x:8443
  "InstallerToken": "<token>",                  // chỉ dùng cho enroll lần đầu
  "AllowUntrustedCertificate": true,            // true nếu server HTTPS self-signed
  "StateDirectory": "C:\\ProgramData\\MProjectAgent"
}
