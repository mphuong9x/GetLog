3. LAY CHU KY DE DAN
--------------------------------------------------------------------------------

Chu ky da in san o cuoi buoc 2. Neu can copy lai:

  Get-Content .\artifacts\MProjectAgent-2.1.0.0.zip.signature.txt -Raw | Set-Clipboard

Neu da co zip san, chi muon ky lai (khong build lai):

  powershell -NoProfile -ExecutionPolicy Bypass -File scripts\sign-agent-release.ps1 -Sign -ArchivePath .\artifacts\MProjectAgent-2.1.0.0.zip

Muon tu kiem tra chu ky truoc khi upload (Git Bash):

  openssl base64 -d -in artifacts/MProjectAgent-2.1.0.0.zip.signature.txt -out /tmp/rel.sig
  openssl dgst -sha256 -verify agent-release-public.pem -signature /tmp/rel.sig artifacts/MProjectAgent-2.1.0.0.zip
  # ket qua mong doi: Verified OK

O "Release signature (base64)" tren web la CHU KY cua dung file zip do,
KHONG PHAI public key trong appsettings.json. Moi ban zip mot chu ky khac nhau.

--------------------------------------------------------------------------------

    chi chao khi ban active CAO HON version tram bao, hoac release bat ForceApply.

 2. Tram KHONG tai ngay: dat lich ngau nhien trong 0-900 giay (UpdateJitterSeconds)
    de 2000 may khong cung tai mot luc. Vai phut dau khong thay gi la BINH THUONG.

 3. Tai zip qua API server -> kiem SHA-256 khop -> verify chu ky bang public key
    cua tram. Sai bat ky dieu nao -> ghi outcome "rejected", KHONG cai.

 4. Giai nen vao C:\ProgramData\MProjectAgent\update\staging roi chay apply-update:
      - sc stop MProjectAgent (cho toi da 60s; khong dung duoc -> huy, bat lai,
        khong dung file nao)
      - kill MProjectLauncher.exe (no khoa file; agent len lai tu bat launcher)
      - backup toan bo thu muc cai -> update\backup
      - copy de, BO QUA moi appsettings*.json o goc  => config tram giu nguyen
      - sc start; len RUNNING -> "applied"
        khong len -> TU ROLLBACK tu backup -> "rolled_back"

 5. Heartbeat ke tiep gui update-result.json len -> web hien adoption band
    (Dung ban active / Cu hon / offline) + cot lich su update cua tung may.

 6. Neu that bai: thu lai sau 5 phut -> 20 phut -> 80 phut -> toi da moi 6 tieng.
    Khong bao gio hot-loop tai lai lien tuc.
